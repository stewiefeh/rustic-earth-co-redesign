# Rustic Earth Tea & Spice Co. — site redesign concept

A one-page redesign concept for Rustic Earth Tea & Spice Co.
(rusticearthco.com), a family-run tea and spice pantry in Dennis Township
and the Berlin Farmers Market, New Jersey.

Everything on the page is real, pulled from the shop's live listings in
October 2026: category counts, product names, prices, store hours,
addresses and phone. Product and category links go to the live store.

Hand-built. Static HTML, CSS and vanilla JS. No frameworks, no build step.
Fonts: Fraunces + Karla (Google Fonts). The hero photograph is an original
illustration; product photos belong to Rustic Earth Co.

Motion: one orchestrated page-load sequence in the hero, scroll-triggered
staged reveals per section, and a slow stamp-ticker for the shop's Mythical
Meats snack-stick lineup. Transitions animate transform and opacity only.
`prefers-reduced-motion` gets the full content with the animation removed,
and the page renders complete without JavaScript.

Live on GitHub Pages: https://stewiefeh.github.io/rustic-earth-co-redesign/
